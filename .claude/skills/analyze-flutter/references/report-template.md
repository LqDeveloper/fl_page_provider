# 报告模板：package分析报告.md

这份报告有两类读者：**人**（决定改什么、排期）和 **AI 工具**（检索定位、自动应用修复）。所以格式是硬约束，不是风格建议——字段名、顺序、`路径:行号` 的写法都要严格一致，否则机器解析不了。

写完必须跑校验：

```bash
python3 <skill>/scripts/verify_report.py <package>/package分析报告.md <package>
```

它会逐条检查文件是否存在、行号是否越界、**锚点在源码里是否真的找得到**、**「现状」代码块是否逐字来自源文件**。有 ❌ 就是这条不可信，回去核对源码改正，**不要交出没通过校验的报告**。

## 二、P0 问题

### P0-1 `AnimationController` 未在 dispose 中释放

**定位** `lib/src/banner.dart:34-37`
**锚点** `_controller = AnimationController(vsync: this`
**现状**
```dart
_controller = AnimationController(vsync: this, duration: _kDuration)
  ..repeat();
```
**机制** `vsync: this` 把 controller 注册到 Ticker 上并持续接收帧回调。State 销毁后它仍持有 `this`，整棵子树无法 GC；debug 下抛 `was disposed with an active Ticker`。
**改法**（替换 `lib/src/banner.dart:120-123` 的 `dispose`）
```dart
@override
void dispose() {
  _controller.dispose();
  super.dispose();
}
```
**风险** 低。需确认没有异步回调在 dispose 后仍访问 `_controller`。
**难度** 低。1 处改动。
**验证** `_controller.dispose();` — 反复进出该页面内存不再单调上涨。
**状态** ✅ 已修复 2026-09-07（复查：验证条件成立）

## 硬约束

**字段名和顺序固定**：`定位 / 锚点 / 现状 / 机制 / 改法 / 风险 / 难度 / 验证 / 状态`。一个不能少，不能改名，不能调换。机器按这个解析。

**状态** 取三种之一，首次出报告时一律写 `待修复`：

| 值 | 含义 |
|---|---|
| `待修复` | 尚未处理 |
| `✅ 已修复 YYYY-MM-DD（一句依据）` | 已改并复查通过 |
| `⏭ 不修（原因）` | 评估后决定不改，**必须写原因** |

**已修复的条目不要从报告里删掉**——留着才有改造记录，也便于回归时对照。索引表的「状态」列和头部的「修复进度」要同步更新。

**定位** 必须是 `路径:起-止`，路径相对 package 根，不带前缀说明文字。

**锚点** 是从源文件里**复制**出来的一行（或半行）原文，在该文件中唯一——AI 工具靠它定位改哪一处。**直接取扫描输出或 Read 结果里的那一行，不要重新敲，也不要逐条 grep 去验**——`verify_report.py` 会一次性把存在性、唯一性、行号、逐字性全查掉，逐条 grep 是重复劳动。校验报"出现 N 次"时再换更长的片段。**编不出锚点，说明这条问题你没真正读过代码，删掉它。**

**现状** 必须逐字来自源文件，只允许用 `// ...` 省略中间无关行。**不许凭记忆改写**——校验脚本会逐行比对，对不上直接判 FAIL。

**改法** 当「可机械修复=是」时，必须是能**直接替换现状代码块**的完整片段；替换目标不是现状那几行时，在括号里写明替换哪个范围。结构性改造（拆类、抽接口、引入泛型）标「否」，并给分步骤，不要假装能一键替换。

**验证** **必须以一个反引号代码片段开头**，那是"修复后应该能在文件里搜到的代码事实"，后面用 ` — ` 接一句人话说明。格式：

```
**验证** `_controller.dispose();` — 反复进出该页面内存不再单调上涨。
```

`--recheck` 就是靠这个片段判断是否已修复的。**不要用锚点来判断修复**——很多修复（往 `dispose()` 里补一行）根本不会动到锚点那一行，锚点永远还在。所以这个片段要选**只有改完之后才存在**的代码。

**机制** 1–3 句，讲清 Flutter 的哪个机制导致它出问题。写不出机制的，降级为"可疑，建议关注"或直接删掉。

**代码片段 ≤15 行**，只贴相关那几行。贴整个类既没人看，也会让锚点唯一性判断变复杂。
